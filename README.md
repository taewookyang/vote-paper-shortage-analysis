# 투표용지 부족 사태 공개 데이터 검증

2026년 6·3 지방선거 투표용지 부족 사태에서 **확인된 사실**, **공개 데이터로 계산한
스트레스 테스트**, **아직 공개되지 않은 정보**를 분리해 보여주는 시민 데이터 프로젝트입니다.

- 대시보드: https://dashboard-weld-eight-19.vercel.app
- 저장소: https://github.com/taewookyang/vote-paper-shortage-analysis
- 현재 상태: [`docs/CURRENT_STATUS.md`](docs/CURRENT_STATUS.md)
- 면책 및 해석 원칙: [`DISCLAIMER.md`](DISCLAIMER.md)

## 현재 확인된 핵심

| 구분 | 현재 확인 범위 |
|---|---|
| 선관위 공식 집계 | 전국 67곳 추가 송부, 22곳 투표 중단 |
| 실제 부족 구분 | 실제 부족 50곳, 미사용 추가 송부 17곳 |
| 중단 위치 공개 수준 | 중앙선관위 투표소명 명단 미공개, 언론 보도상 중단 3곳 |
| 지역선관위 설명상 지연 | 인천 연수구 2곳 |
| 언론 보도상 지연 | 송파구 가락2동 2곳 |
| 상세 위치 | 언론 보도에 이름이 등장한 부족·중단·지연 투표소 16곳 |
| 직접 선거구 연결 | 보도 위치 16곳을 광역·기초의원 선거구에 연결 |
| 전국 수요 기준선 | 256개 구시군, 동별 선거일 수요 3,558행 |
| 전국 표차 기준선 | 광역·기초의원 1,540개 선거구 |

송파구에 50%를 일률 적용한 계산에서는 구 전체 여유가 남지만 일부 투표소에서는 실제
부족이 확인됐습니다. 이 차이를 설명하려면 **투표소별 최초 배부량, 추가 송부 요청·도착
시각, 중단·재개 기록**이 필요합니다.

`+42,774장`은 실제 잔여 투표용지가 아니라 송파구 전체 선거인수에 50%를 일률 적용한
계산상 수량과 선거일 투표자 수의 차이입니다.

## 화면을 읽는 순서

1. **공식 확인:** 추가 송부·중단 집계
2. **증거 구분:** 선관위 구별 집계, 언론 보도 위치, 모델 조사 후보
3. **직접 연결 확인:** 언론 보도에 이름이 등장한 투표소와 선거구
4. **스트레스 테스트:** 50% 일률 가정에서 여유가 작아질 수 있는 동
5. **위치 미확인 참고:** 추가 송부 발생 구시군의 표차 기준선
6. **자료 공백:** 현재 데이터로는 판단할 수 없는 항목

표차는 선거 결과 영향의 증거가 아닙니다. 500표 기준은 운영 기록 확인 순서를 좁히기
위한 편의상 기준입니다.

## 현재 알 수 없는 것

- 공개되지 않은 전체 67개 추가 송부·22개 중단 투표소의 정확한 위치
- 투표소별 실제 최초 배부량과 비상 이송 수량·시각
- 투표 중단 시간과 대기·이탈 유권자 수
- 투표용지 부족이 선거 결과에 미친 영향

## 데이터와 방법

- 중앙선관위 VCVP01: 시간대별 투표진행현황
- 중앙선관위 VCCP08: 동별 선거인수·선거일 투표자·선거 결과
- 언론 및 공개 브리핑: 부족·중단 투표소 위치 보강
- Python·Node.js 배치 파이프라인: 수집, 정규화, 검증, 정적 JSON 생성
- React·Vite: 정적 대시보드

상세 방법론은 [`METHODOLOGY.md`](METHODOLOGY.md), 데이터 파이프라인은
[`docs/DATA_PIPELINE.md`](docs/DATA_PIPELINE.md)를 참고하세요.

## 실행 및 검증

```bash
python scripts/build_shutdown_stress_test.py
python scripts/build_known_location_margin_mapping.py
python scripts/merge_national_overnight.py
python validate_pipeline.py --strict

cd dashboard
npm install
npm run build
npm run smoke:local
```

`validate_pipeline.py --strict`의 남은 경고는 오류가 아니라 상세 투표소명 공개 범위가
67곳 중 16곳에 그친다는 자료 한계입니다.

## 공개 원칙

- 확인된 사실과 계산·가정을 같은 표현으로 섞지 않습니다.
- 특정 정당·후보 유불리, 고의성, 당락 영향을 단정하지 않습니다.
- 동 평균 수요를 투표소별 실제 부족량으로 표현하지 않습니다.
- 시간대별 집계 급증을 부족 발생 시각으로 해석하지 않습니다.
- 실제 배부·이송 기록 확보 전에는 당락 영향 추정 모델을 확장하지 않습니다.

편집 원칙은 [`docs/DASHBOARD_EDITORIAL_GUIDE.md`](docs/DASHBOARD_EDITORIAL_GUIDE.md)에
기록합니다.
