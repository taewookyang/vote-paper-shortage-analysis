# 대시보드 편집 원칙

## 한 문장 목표

확인된 부족·중단 사실과 공개 데이터로 계산한 스트레스 테스트를 분리해 보여주고,
선거 결과 영향을 단정하지 않은 채 추가 공개가 필요한 운영 기록을 구체화한다.

## 정보 표시 순서

1. 선관위가 공식 확인한 사실
2. 이름과 위치가 확인된 투표소의 직접 연결 결과
3. 50% 일률 적용 가정의 스트레스 테스트
4. 위치가 확인되지 않은 광범위 참고 목록
5. 현재 데이터로 알 수 없는 것과 필요한 자료

## 증거 수준별 표현

| 수준 | 사용할 표현 | 피할 표현 |
|---|---|---|
| 공식 확인 | `추가 송부 확인`, `중단 확인` | `피해 확정`, `결과 영향` |
| 위치 직접 연결 | `운영 기록 우선 확인 대상` | `당락 영향 선거구` |
| 계산·가정 | `50% 가정상 여유`, `스트레스 테스트 후보` | `실제 잉여`, `부족량`, `위험 지역` |
| 미확인 | `공개 자료로 산정 불가`, `추가 공개 필요` | `기록이 없다`, `은폐됐다` |

## 필수 설명

- 표차는 선거 결과 영향의 증거가 아니다.
- 동 평균 수요는 투표소별 실제 배부량이나 부족량이 아니다.
- 오후 1시 투표율 급증은 사전투표 합산에 따른 집계 변화이며 부족 발생 시각이 아니다.
- 500표 기준은 법적 기준이 아니라 자료 확인 순서를 좁히는 편의상 기준이다.

## 다음 작업 우선순위

1. 67개 추가 송부·22개 중단 투표소의 정확한 이름과 위치 보강
2. 투표소별 최초 배부량, 추가 송부 요청·도착 시각, 중단 시간 확보
3. 2018·2022년 실제 배부량과 비상 재고 기록 확보
4. 핵심 주장별 출처 URL·증거 수준·최종 확인일을 보여주는 방법론 화면 추가
5. 전국 지도는 `공식 확인`, `위치 확인`, `가정상 후보`, `미확인` 레이어를 분리해 구현

실제 배부·이송 기록이 확보되기 전에는 당락 영향 추정 모델을 확장하지 않는다.
