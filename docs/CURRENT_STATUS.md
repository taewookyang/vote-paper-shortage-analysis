# 현재 작업 상태

기준일: 2026-06-07

## 현재 가능한 분석

- 전국 추가 송부 67곳, 실제 부족 50곳, 미사용 추가 송부 17곳을 구분한다.
- 중앙선관위가 공식 발표한 5개 구별 중단 수 합계 22곳을 보존한다.
- 중앙선관위가 투표소명 22개를 공개한 명단은 아직 확인되지 않았다.
- 언론 현장 보도상 중단 위치 3곳, 언론 보도상 지연 위치 2곳, 인천선관위 설명 인용 보도상 지연 위치 2곳을 별도 보존한다.
- 언론 보도에 이름이 등장한 부족·중단·지연 위치 16곳을 보존한다.
- 대상 5개 구에서 50% 배부 가정 동 단위 스트레스 테스트를 수행한다.
- 추가 송부 발생 27개 구시군의 광역·기초의원 212개 선거구 표차를 검토한다.
- 전국 광역·기초의원 1,540개 선거구의 당선권 경계 표차 기준선을 수집했다.
- 전국 256개 구시군의 동별 선거일 투표 수요 3,558행을 수집했다.
- 언론 보도에 이름이 등장한 투표소 16곳을 선관위 결과표 기준 광역·기초의원 선거구에 직접 매핑했다.

## 아직 할 수 없는 분석

- 공개되지 않은 전체 22개 중단 투표소의 위치 특정
- 투표소별 실제 배부량과 비상 이송 시점 확인
- 투표를 포기하고 돌아간 유권자 수 추정 또는 선거 결과 영향 단정
- 상세 위치가 없는 추가 송부 투표소를 특정 선거구에 임의 매핑

## 정식 산출물과 중간 산출물

- 정식 원자료: `data/raw/`
- 정식 분석 산출물: `data/processed/`
- 실제 배포 데이터: `dashboard/public/data/`
- `*_worker_*_of_*` 파일은 병합 전 중간 산출물이며 Git 추적 대상이 아니다.
