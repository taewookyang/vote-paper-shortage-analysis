# 데이터 파이프라인 설계

## 목적

파이프라인은 확인된 사실, 계산된 값, 가정 기반 추정치를 분리한다. 송파구 파일럿과
전국 확장에 동일한 검증 규칙을 적용하며, 검증을 통과하지 않은 원본은 대시보드
분석값으로 승격하지 않는다.

## 단계

```text
선관위 웹/API·언론 출처
  -> data/raw 원본 보존
  -> 스키마 정규화
  -> validate_pipeline.py 검증
  -> 동·선거구·구시군 분석 테이블
  -> 대시보드 JSON
```

## 분석 단위별 기준 데이터

| 분석 단위 | 기준 데이터 | 이유 |
|---|---|---|
| 동별 선거일 수요 | 구·시·군의장 개표결과 | 한 동이 한 번만 나타남 |
| 구의원 후보 득표·표차 | 구의원 선거구별 개표결과 | 후보와 선거구 정보 보존 |
| 관외사전투표 성향 | 해당 선거구 또는 구시군 별도 단위 | 공개자료에서 동별 배분 불가능 |
| 투표소 부족 여부 | 언론·선관위 확인 명단 | 개표결과로 부족 여부 추론 금지 |
| 시간대별 유입 | VCVP01 누적 투표현황 | 누적값 단조 증가와 합계 검증 필요 |

관외사전투표를 동별로 임의 배분하지 않는다. 동별 분석에서는 제외하고, 최종
선거구 표차와 선거구 단위 성향 분석에는 포함한다.

## 자동 검증 규칙

- 필수 열과 출처 URL 존재
- 동·선거구·시간대 키 중복 없음
- 동별 `계 = 관내사전투표 + 선거일투표`
- 구시군 `합계 = 동별 계 + 거소 + 관외사전 + 기타`
- 후보별 득표 합 = 후보득표계
- 투표수 = 후보득표계 + 무효투표수
- 선거인수 = 투표수 + 기권자수
- 시간대별 누적 투표자 수 단조 증가
- 전국 코드 목록 대비 수집 완료 구시군 수
- 부족 명단 `67 추가송부 / 50 실제부족 / 17 미사용` 보존
- 중단 지역 스트레스 테스트에서 공식 수치·확인 위치·모델 후보의 증거수준 분리

## 22곳 중단 지역 스트레스 테스트

`scripts/build_shutdown_stress_test.py`는 다음 자료를 결합한다.

- `data/raw/national_dong_turnout.csv`: 동별 선거일 수요
- `data/raw/shortage_2026.csv`: 이름이 공개된 실제 부족·중단 위치
- `data/processed/shortage_gu_polling_places.csv`: 대상 5개 구 전체 투표소 목록

산출물 `shutdown_stress_test_2026.json`의 `model_candidates`는 실제 중단 위치 예측이
아니다. 동 평균 선거일 수요가 50% 배부 가정을 넘는 추가 조사 후보이며, 각 행은
`confirmed_shutdown`, `confirmed_shortage`, `model_candidate` 중 하나의 증거수준을
가진다.

## 이름 공개 투표소의 선거구 직접 매핑

```bash
node scripts/collect_district_dong_mapping.cjs
python scripts/build_known_location_margin_mapping.py
```

첫 명령은 선관위 VCCP08 결과표에 실제 등장하는 읍면동을 광역·기초의원 선거구에
연결한다. 두 번째 명령은 이름이 공개된 부족·중단 투표소와 당선권 경계 표차를
결합한다. 상세 위치가 공개되지 않은 투표소는 임의로 선거구에 배정하지 않는다.

실행:

```bash
python validate_pipeline.py
python validate_pipeline.py --strict
python run_pipeline.py
```

검증 결과:

- `data/processed/pipeline_audit.json`
- `data/processed/pipeline_audit.md`

## 과거 선거 비교

“지난 선거에는 문제가 없었다”는 결론은 공개 개표자료만으로 확인할 수 없다.
연도별로 다음 항목을 비교한다.

1. 동별 선거일 수요가 선거인수의 50%를 넘은 횟수
2. 50% 가정 대비 최소 여유 장수
3. 사전투표율과 선거일 수요의 관계
4. 실제 부족·추가송부 보도의 존재 여부
5. 당시 배부기준과 비상공급 기록의 공개 여부

수요가 50% 미만이었던 것과 부족 사고가 없었던 것은 같은 의미가 아니다. 실제
배부량과 비상공급 기록이 없으면 “문제가 없었다”가 아니라 “확인되지 않았다”고
표시한다.

## 전국 확장 순서

1. 서울 25개 구 수집 완료와 합계 검증
2. 2026 부족 발생 시도 6곳 우선 수집
3. 전국 코드 목록의 256개 구시군 동별 수요 수집
4. 작은 표차의 기초의원 선거구 결과 수집
5. 2018·2022 동일 구조 정규화
6. 검증 통과 데이터만 전국 대시보드에 노출
