# 지도 경계 데이터 결정 기록

기록일: 2026-06-06

## 목표

- 전국 화면은 시도·시군구 실제 경계 지도로 표시한다.
- 지역 상세 화면은 송파구처럼 자료가 충분한 지역만 행정동 실제 경계로 표시한다.
- 지도에서는 `실제 부족 확인`, `50% 하한 초과`, `50% 이하`를 구분한다.
- 실제 확인 사실과 가정에 따른 분석 결과를 같은 색이나 표현으로 섞지 않는다.

## 현재 구현

- `scripts/build_songpa_boundaries.py`
  - 행정동 경계 원본에서 송파구 27개 동만 추출한다.
  - 브라우저용 SVG path JSON으로 변환한다.
- `dashboard/src/Dashboard.jsx`
  - 송파구 실제 경계 지도 UI를 추가했다.
  - 동 선택, 범례, 당일투표율, 실제 부족 확인 투표소 수를 표시한다.
- 경계 데이터 산출물은 아직 저장소에 포함하거나 배포하지 않는다.

## 라이선스 검토

검토 후보는 `vuski/admdongkor`이다. 최신성 및 행정동 변경 이력 품질은 좋지만,
저장소에 별도 `LICENSE` 파일이나 SPDX 라이선스가 없다.

- 확인 요청 이슈: https://github.com/vuski/admdongkor/issues/14
- 답변 전까지 경계 데이터는 참고·로컬 개발 용도로만 사용한다.
- 지도 렌더링 코드와 변환 스크립트는 프로젝트 코드로 관리한다.

## 답변 이후 처리

1. 가공 및 재배포 허락이 명확하면 출처와 데이터 라이선스를 표시하고 사용한다.
2. 허락 범위가 불명확하면 UI는 유지하고 공식 SGIS 경계 취득 방식으로 교체한다.
3. 전국 확대 시 원본 전국 경계를 브라우저에 직접 제공하지 않고 필요한 단계별 경계만 단순화한다.
